三黄泻心汤的药理研究概况

y由: TsingHua    

作者: 蒋爱品; 北京中医

 

三黃瀉心湯由大黃、黃連、黃芩組成 ,商朝伊尹所創 ,相傳伊尹是最早的中醫方劑學著作《湯液經》的作者 ,所以 ,後人將三黃瀉心湯稱為伊尹三黃瀉心湯<1 > 。一般認為三黃瀉心湯出自《金匱要略》 ,方中大黃二兩 ,黃連一兩 ,黃芩一兩 ,以水三升 ,煮取一升 ,頓服之。

本方為治療熱盛吐衄証要方。以黃連瀉心清胃 ,燥濕解毒 ;黃芩瀉肺燥濕解毒 ;大黃瀉火通腑瀉毒 ,引火下行。故全方能瀉火解毒 ,燥濕瀉熱。主治胃火熾 ,破火妄行 ,以致吐衄 ,便秘 ,或三焦實熱 ,高熱煩躁 ,神昏便秘 ,面紅目赤 ,口舌生瘡 ,濕熱黃疸 ,霍亂等症<2 > 。

其主要藥理作用有 :

一、抗病原微生物作用本方及其加減方均有抗菌作用 ,如可抑制葡萄球菌、費氏痢疾杆菌、大腸杆菌的生長。本方 1 0 %的煎劑對羊毛樣小孢子菌等皮膚真菌也有抑制作用<2 > 。用於治療急性肺炎、老年性肺炎、急性化膿性扁桃腺炎及眼部炎症<3～ 6>等。用三黃甘草湯 (黃芩、黃柏各 3 0 ｇ ,黃連 9ｇ ,甘草 6ｇ煎液 ) ,治療顱內感染 ,效果顯著<7> 。實驗証明三藥中黃連、黃芩、大黃均有抗菌作用 ,且三藥中任兩藥合用或三藥合用抑制作用均增強 ,黃連的抗菌成分為黃連素及巴馬亭 ,黃芩為黃酮類 ,大黃為蒽醌類<2 > 。

二、對心血管系統及血液系統的影響

  1. 抗凝血　本方治療缺血性腦血管疾病有一定療效 ,如腦血栓、預防腦卒中<8> 等 ,該類病的發生和發展的根源在於血液的高凝狀態 ,尤以血小板凝集性亢進為重要 ,在體內血小板聚集活性受花生四烯酸 (ＡＡ)代謝的調節 ,其環氧酶途徑代謝產物血栓素ＴＸＡ2 可引起強烈的血管收縮和血小板凝聚。腦血栓形成時患者體內ＴＸＡ2 增高。另外 ,ＡＡ代謝之脂氧化酶途徑產物也影響血凝過程 ,如具有強烈血小板凝集活動的血小板活化因子 (ＰＡＦ)的生成和釋放與脂氧酶代謝有關。瀉心湯可以改善血液的高凝狀態 ,從而防止腦卒中的發生。黃芩甙可阻止血小板前列腺素的代謝 ,還可抑制白細胞脂質氧化酶 ,抑制肥大細胞、嗜鹼細胞膜表面的抗原抗體反應以及高密度脂蛋白、膽固醇的增加。大黃、黃連對腸內菌群的調整 ,可能有抑制內毒素的產生 ,從而抑制血小板的凝集作用<1 0 > 。

  2. 降壓　常用於治療Ⅰ期高血壓。本方對高血壓和伴有紅細胞壓積上升的Ｇａｉｓｃｋ綜合征 (高血壓性紅細胞增多 )的病例有效 ,又可鎮靜、降壓、降血脂 ,因此 ,對腦出血、腦梗塞有預防作用<1 1 > 。實驗証明 :三藥單用均無降壓作用 ,而三黃丸卻有降壓作用 ,故認為三黃丸中含有影響調節血壓的酶系統 ,如增強酪氨酸酶活性 ,抑制組胺酸脫羧酶及透明質酸酶活性。能顯著降低去甲腎上腺素濃度及腎素 -血管緊張素 -醛固酮系統活性<2 > 。

  3. 改善高脂血症　三黃瀉心湯能使低密度脂蛋白膽固醇 (ＬＤＨ)、膽固醇和甘油三酯降低 ,顯示降血脂的效果。單味黃連、黃芩、大黃均無降血脂作用 ,但黃芩、黃連合用 ,可使膽固醇水平下降 ;黃連、大黃合用可使血中中性脂肪減少 ;黃芩、大黃合用則使總脂質和中性脂肪均降低 ;三藥合用則降血脂作用因大黃用量增多而增強 ,至三者等量時 ,(即三黃丸 )降血脂作用最強。

  4. 改善血液粘稠度　三黃瀉心湯治療高過氧化脂質和抗凝血酶Ⅲ活性降低的高粘度血症 ,在改善血清過氧化脂質和抗凝血酶Ⅲ的同時 ,改善血液粘稠度 ,並改善血清皮質酮以及肝臟腫大的異常<2 > 。

三、止血作用三黃瀉心湯可治療各種出血 ,如急性出血、吐血、衄血、咳血。三黃瀉心湯可縮短正常小鼠出凝血時間 ,縮短血漿復鈣時間 ,並可對抗利血平所誘發的小鼠胃粘膜出血和潰瘍的發生 ,抑制大鼠幽門結扎所致的胃潰瘍形成<1 2 ,1 3> 。三黃瀉心湯加味治療上消化道出血 50例,有效率 96% ,認為方中大黃起主要作用 ,可抑制上消化道運動 ,使細胞外液向血管內轉移 ,使血液稀釋 ,同時可降低毛細血管脆性 ,使纖維蛋白增加 ,促進血液凝固<1 4 > 。由三黃瀉心湯研制的血寧沖劑對潰瘍或炎症所致的上消化道出血、胃癌和再生障礙性貧血所致的出血均有止血作用。認為 ,本方有增強凝血系統和抗纖溶作用<1 5～ 1 6> ;促進循環內血小板聚集率 ,使血小板聚集增多。方中大黃對上消化道出血的止血作用最突出 ,其機理是大黃能增加血液粘度、纖維蛋白原量 ,增高紅細胞聚集性、減慢微小血管血流速度 ,縮短血凝和出血時間 ,提高兔及人體離體血管條的緊張性與收縮力 ,增加其自發節律 ,抑制上消化道的運動及抑制胃蛋白酶的活性等<2 > 。

四、降血清氮質作用三黃瀉心湯可使血中尿素氮降低 ,而使總膽固醇升高。用於治療急、慢性腎功能衰竭。認為大黃中的大黃鞣質是降尿素氮的有效成分 ,通過抑制機體蛋白質分解 ,提高氨對谷酰胺生成的利用率而使尿素氮含量降低。實驗還發現大黃鞣質可抑制腺嘌呤所致腎功能不全大鼠的腎重量的增加 ,使尿素氮和肌酐降低 ,用於慢性腎功能衰竭。<2 >

五、抗炎作用以黃芩甙、大黃浸膏、黃連素為原料制成的“三黃片” ,實驗証明可降低小鼠腹腔毛細血管通透性 ,對醋酸及二甲苯所致的炎症有明顯的抗炎作用<7> 。

六、對胃粘膜的保護作用三黃瀉心湯能抑制五肽味泌素和 2 -去氧葡萄糖引起的胃酸分泌<1 7> 。通過減少鈉、氫離子從粘膜向胃內腔的流量 ,從而抑制牛磺膽酸鹽引起的胃粘膜損傷 ,並且可促進胃粘膜合成ＧＰ(胃粘膜前列腺素 ) ,增強胃粘膜的防御技能。<1 8>

七、其他作用

  1. 抑制抗癌藥的毒性　抗癌藥Ｃisplatin (順氯氨鉑 ) ,對部分膀胱、卵巢、睪丸癌及胃癌有效 ,但可產生強的腎毒性、骨髓毒性、神經毒性 ,三黃瀉心湯在投藥前 4-7天內服用 ,有效率為 1 0 0 %。<1 9>

  2. 調節精神、情緒　用於焦虛、不安的精神分裂症 ,三黃瀉心湯顯示速效的鎮靜作用<2 0 > 。

  3. 利膽保肝作用　瀉心湯可改善苯肼所致中毒家兔的肝腎功能<2 > 。
